# Release-notes PDFs (manual fallback only)

**You normally don't need this folder.** The advisor finds the latest release and exports its official release notes PDF from help.salesforce.com automatically.

Use this folder only if the automatic export ever stops working:

1. Open the release notes on help.salesforce.com, for example [Winter '27](https://help.salesforce.com/s/articleView?id=release-notes.salesforce_release_notes.htm&release=264&type=5).
2. Click **PDF** and save the file here.

**Naming:** any filename works. The release is read from the filename (for example `winter27.pdf`) or, if the name doesn't say, from the PDF's cover page.

**Precedence:** a PDF in this folder takes priority over the automatic export for that release. Delete it to go back to automatic.
